# 🎨 Landing Page Section Visual Diversity Plan

**Purpose**: Replace repetitive box layouts with varied, engaging presentations  
**Goal**: Keep users engaged through visual variety while maintaining brand consistency  
**Date**: October 30, 2025

---

## 🎯 Problem Identified

**Current State**: All sections use similar box/card layouts
- Income Stage: 5 identical boxes
- Visa Stage: 4 identical boxes  
- Accommodation Stage: 4 identical boxes
- Community Stage: 3 identical boxes

**Issue**: Repetitive, boring, users lose interest

**Solution**: Each section gets a unique visual treatment

---

## 🎨 Visual Diversity Strategy

### Design Principles:
1. **Varied Layouts**: No two sections should look the same
2. **Intuitive**: Information hierarchy should be clear
3. **Brand Consistent**: Maintain dark theme, red accents
4. **Mobile Friendly**: All variations must work on mobile
5. **Purposeful**: Layout should match content type

## 📱 Mobile Considerations

### Adaptations for Mobile:

**Comparison Tables** → **Swipeable Cards**
```
Desktop: Side-by-side table
Mobile: Horizontal scroll through cards
```

**Bento Grids** → **Stacked Blocks**
```
Desktop: Asymmetric layout
Mobile: Full-width stack
```

**Split Panels** → **Accordion**
```
Desktop: Left/right split
Mobile: Expandable sections
```

**Course Cards** → **2x2 Grid or Scroll**
```
Desktop: 4 cards in row
Mobile: 2x2 grid or horizontal scroll
```

## 📏 Design Specifications

### Course Cards (Gradient Style):
```css
Height: 280-320px
Gradient Header: 180-200px
Content: 80-120px
Grid: 4 columns (desktop), 2 (tablet), 1 (mobile)
```

### Comparison Table:
```css
Columns: 3-4 visa types
Rows: 5-6 key attributes
Mobile: Convert to cards, horizontal scroll
```

### Bento Grid:
```css
Large card: 2x2 grid cells
Small cards: 1x1 grid cells
Gap: 24px
Mobile: Stack full-width
```

### Progressive Steps:
```css
Layout: Zigzag or linear flow
Arrows: Connecting elements
Mobile: Vertical timeline
```
