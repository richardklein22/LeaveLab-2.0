# Partner Images

This folder contains official partner logos and banners for the LeaveLab landing page.

## Current Partners

### Worldpackers
- **File**: `worldpackers-banner.svg` (placeholder - replace with official banner)
- **Usage**: Official Partners section on landing page
- **Dimensions**: Optimized for web display
- **Format**: SVG for scalability, but PNG/JPG also supported

## How to Replace with Official Banner

If you have the official Worldpackers banner image:

1. **Download the official banner** from Worldpackers' media kit or partner portal
2. **Save it** to this folder as `worldpackers-banner.png` or `worldpackers-banner.jpg`
3. **Update** `src/app/page.tsx` to reference the correct filename
4. **Recommended specs**:
   - Width: 1200px - 1600px
   - Height: 300px - 500px
   - Format: PNG (with transparency) or JPG
   - File size: Under 200KB for optimal performance

## Performance Notes

- Next.js automatically optimizes all images in the `/public` folder
- Images are lazy-loaded and served in modern formats (WebP) when supported
- No need to manually optimize - Next.js handles this automatically
