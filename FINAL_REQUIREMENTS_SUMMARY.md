## 🎨 Design Requirements (Your Specs)

### ✅ Simple & Minimal
- **Minimal text**: Max 2-3 lines per description
- **No emojis**: Use icons only (Lucide React library)
- **Clean layout**: Lots of whitespace
- **Scannable**: Easy to understand at a glance

### ✅ Branding
- **Dark theme**: Dark backgrounds (brand-dark-950, brand-dark-900)
- **Red accents**: Primary color for CTAs, highlights, icons
- **Consistent typography**: Clear hierarchy
- **Card-based**: Glass-morphism cards with backdrop blur

### ✅ Mobile Optimized
- **Sections fit in viewport**: Minimal scrolling within sections
- **No long sections**: Mobile users shouldn't scroll through one section
- **Touch-friendly**: 48px minimum tap targets
- **Single column**: Stack on mobile (or horizontal scroll where appropriate)
- **Fast loading**: Optimized images, smooth animations


### Text Limits (Mobile)
```
Headlines:         Max 2 lines (32px font)
Subheadlines:      Max 2 lines (18px font)
Body text:         Max 3-4 lines (14px font)
Bullet points:     Max 4 items per list (12px font)
```

### Card Specs (Mobile)
```
Width:            90vw (90% viewport width)
Height:           300-400px maximum
Padding:          24px
Icon:             48px × 48px
Title:            18px (max 2 lines)

```

### Colors
```css
/* Backgrounds */
--brand-dark-950: #0A0A0A;    /* Main background */

/* Primary */
--brand-red: #EF4444;         /* CTAs, icons, highlights */

/* Accents */
--brand-accent: #8B5CF6;      /* Purple accent */
--brand-accent-pink: #EC4899;  /* Pink accent */
--brand-accent-orange: #F59E0B; /* Orange accent */

/* Text */
--white: #FFFFFF;              /* Headlines */
--gray-300: #D1D5DB;          /* Body */
--gray-400: #9CA3AF;          /* Secondary */
--gray-500: #6B7280;          /* Captions */
```

### Typography Scale
```
H1: 48px → 32px (mobile)
H2: 36px → 24px (mobile)
H3: 24px → 18px (mobile)
Body: 16px
Small: 14px
Caption: 12px
```

### Spacing Scale
```
Section padding:
- Desktop: py-20 (80px)
- Mobile: py-12 (48px)

Card padding:
- Desktop: p-8 (32px)
- Mobile: p-6 (24px)

Gap between elements:
- Desktop: gap-8 (32px)
- Mobile: gap-6 (24px)
```
