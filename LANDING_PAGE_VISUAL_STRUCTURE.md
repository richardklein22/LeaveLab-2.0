## Animation Timeline

### On Page Load:
```
0.0s: Hero headline fades in
0.1s: Hero subheadline fades in
0.2s: Hero CTA button fades in
0.3s: Trust badges fade in
0.4s: Progress icons start appearing
0.5s: Icon 1 (Income) scales in
0.6s: Icon 2 (Visa) scales in
0.7s: Icon 3 (Housing) scales in
0.8s: Icon 4 (Community) scales in
0.8s: Scroll indicator appears & bounces
```

### On Scroll (Viewport-triggered):
```
Section enters viewport → Staggered fade-in
- Heading fades in
- Subheading fades in (0.1s delay)
- Content fades in (0.2s delay)
- List items appear (0.1s delay each)
```

### On Hover:
```
Cards:   Lift up -8px to -12px
Buttons: Scale 1.05x
Links:   Color → Green
Logos:   Grayscale → Color
```

### Auto Animations:
```
CTA Button:    Pulse breathing (2s loop)
Scroll Arrow:  Bounce (continuous)
Testimonials:  Auto-rotate (5s on mobile)
```
