```css
rounded-3xl (24px)  → Border radius
```

## 🚀 Advanced Effects

### **1. 3D Card Tilt**
```css
.card-3d:hover {
  transform: perspective(1000px) 
             rotateX(5deg) 
             rotateY(-5deg) 
             translateZ(10px);
}
```
Cards tilt in 3D space on hover

### **2. Glow Animation**
```css
.animate-glow {
  animation: glow 3s ease-in-out infinite;
  /* Pulsing red shadow effect */
}
```
Red glow pulses on CTAs

### **3. Text Shimmer**
```css
.text-shimmer {
  /* Gradient sweeps across text */
}
```
Subtle shimmer effect

### **4. Float Animation**
```css
.animate-float {
  /* Gentle up/down movement */
}
```
Floating badges and elements

### **5. Glassmorphism**
```css
.glass {
  background: rgba(255, 255, 255, 0.05);
  backdrop-filter: blur(10px);
}
```
Frosted glass effect

### **6. Magnetic Buttons**
```css
.magnetic-button:hover {
  transform: scale(1.05);
}
```
Buttons "pull" towards cursor
