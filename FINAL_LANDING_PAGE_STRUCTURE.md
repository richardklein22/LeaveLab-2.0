## 📱 Mobile-First Optimization Rules

### 1. Section Height Limits
```
Maximum Mobile Section Heights:
- Hero: 100vh (one viewport)
- Roadmap Overview: 90vh (minimal scroll)
- Each Stage: 120vh max (1.2 viewports)
- Partnerships: 100vh
- Success Stories: 120vh per story
- Everything You Get: 100vh
- CTA: 60vh
- FAQ: Auto (accordion)
```

### 2. Text Limits
```
Headlines: Max 2 lines
Subheadlines: Max 2 lines
Body text: Max 3-4 lines
Bullet points: Max 4 items per list
```

### 3. Card Dimensions (Mobile)
```
Width: 90vw (90% of viewport)
Height: 300-400px max
Padding: 24px
Icon: 48px × 48px
Title: 18px (2 lines max)
Description: 14px (2-3 lines max)
```

### 4. Touch Targets
```
Minimum: 48px × 48px
Recommended: 56px × 56px
Spacing between: 8px minimum
```

### 5. Loading Performance
```
Above fold: < 1s
Full page: < 3s
Images: Lazy load below fold
Animations: Reduced motion support
```
